# raw/

Place the untouched EMSCAD dataset CSV here exactly as downloaded from Kaggle
(https://www.kaggle.com/datasets/amruthjithrajvr/recruitment-scam).

Do not edit files in this folder. Treat it as read-only so that all
processed/derived data can always be regenerated from a known starting point.

This folder's contents are excluded from Git (see .gitignore) because the
dataset is large and publicly downloadable — it does not need to be versioned.
